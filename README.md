# PDF 拼接工具

把几个 PDF 合成一个，浏览器里直接搞定，不用装软件也不用传到服务器。

在线体验：[https://pdf-merge-tool-lovat.vercel.app](https://pdf-merge-tool-lovat.vercel.app)

## 能干什么

- 拖文件进来就行，也支持点按钮批量选
- 想调顺序？上移下移随你便，删掉不要的也很方便
- 每个文件都能单独预览，在弹窗里看
- 拼好之后一键下载 `merged.pdf`
- 手机电脑都能用，界面会自动适配

## 怎么用

1. 打开 `index.html`（或者上面的在线地址）
2. 把 PDF 拖进虚线框，或者点"选择文件"
3. 拖进来的文件会显示在列表里，可以调整顺序
4. 点"开始拼接"，等几秒就好
5. 点"下载合并后的 PDF"保存到本地

## 技术方案

整个项目就一个 `index.html`，没用任何框架。

| 用的什么 | 干什么 |
|----------|--------|
| HTML5 | 页面结构 |
| CSS3 | 样式（变量、渐变、弹性布局这些都用上了） |
| 原生 JS | 交互逻辑 |
| [pdf-lib](https://github.com/Hopding/pdf-lib) | PDF 合并，走 CDN 加载 |

## 项目就俩文件

```
index.html    ← 全部代码都在这里
README.md     ← 你现在看的这个
```

## 几点说明

- 文件全程在你浏览器里处理，不会上传到任何地方
- 文件太多或太大的话，拼接可能要多等几秒
- 如果报错，大概率是某个文件不是合法的 PDF
